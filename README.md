## 🚀 Featured Projects

### 🏥 [Trego Backend — B2B Medicine Delivery Platform](https://github.com/connecttrego/trego_backend)
> **Production project built during internship at Letsgain Pvt. Ltd.**

- Built core backend using **Spring Boot & Java** for a B2B medicine delivery and vendor platform
- Designed **RESTful APIs** for vendor inventory, order pipelines, and address management
- Implemented multi-vendor cart logic with **@Transactional** for atomicity & integrated **Razorpay Payment Gateway**
- Worked across the stack on vendor/admin React dashboards — API integration, UI data binding & debugging

`Java` `Spring Boot` `MySQL` `Razorpay` `REST API`

---

### ⭐ [StayGrade — Hotel Rating System](https://github.com/vatsalya0713/microservice-)
> **Microservices architecture project**

- Built microservices backend with **Spring Cloud Gateway**, **Eureka** service discovery & **OpenFeign**
- Used **polyglot persistence** — MySQL, PostgreSQL & MongoDB across different services
- Integrated a responsive **React dashboard** for hotel ratings and catalog management

`Java` `Spring Boot` `Spring Cloud` `MySQL` `MongoDB` `React.js` `Microservices`

---

### 🛒 [Trego VMS — Vendor Management System](https://github.com/vatsalya0713/Trego_Vms)
> **Full-stack personal project**

- Full-stack B2B vendor management platform with **role-based access control** (Admin, Vendor, Rider) using JWT
- Interactive **Recharts** dashboards for business metrics & analytics
- Integrated **Twilio API** for SMS notifications & OTP verification
- MySQL-backed cart and real-time order tracking flow

`React.js` `Node.js` `Express.js` `MySQL` `JWT` `Tailwind CSS` `Twilio` `Recharts`
